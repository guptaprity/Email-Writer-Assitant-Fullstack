# Smart Email Writer ✉️🤖

An **AI-powered full-stack web application** that helps users generate professional and well-structured emails instantly using AI. Built with **Java Spring Boot** on the backend and **React** on the frontend, this project demonstrates real-world backend development, REST API design, AI integration, and cloud deployment.

---

📽 **Demo Video:** Available on LinkedIn

---

## 🧩 Problem Statement

Writing professional emails can be time-consuming and challenging, especially for formal or business communication. This project solves that problem by allowing users to generate high-quality email content by simply providing context or intent.

## 📂 API Overview

### Generate Email

**Endpoint:**

```
POST /api/email/generate
```

**Request Body (Example):**

```json
{
  "prompt": "Write a professional follow-up email after an interview"
}
```

**Response:**

```json
{
  "email": "Dear Hiring Manager, ..."
}
```
